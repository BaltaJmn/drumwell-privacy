# drumwell-privacy

Public web of **Drumwell**, a drum tuner for iPhone. To be served at
<https://drumwell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `drumwell` to
`baltajmn.github.io`, proxied), like `bondwell-privacy`. Not published yet: no repository, no DNS.

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall and Settings and in the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `dw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Drumwell`.
